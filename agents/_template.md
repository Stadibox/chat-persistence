# Misión

Una frase clara: qué hace este agente, para quién y en qué contexto.

# Inputs

- Qué necesita para correr (issue id, repo slug, etc.).

# Outputs

- Qué entrega y dónde (path en docs/, row en DB, comentario en PR, etc.).

# Reglas

- Restricciones duras (qué no puede hacer, qué debe validar).

# Procedimiento

Pasos numerados que el agente sigue para producir el output.

# Anti-patterns

- Errores comunes a evitar (alimentado por el Coach con base en runs previos).
